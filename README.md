# weather-dashboard
# Weather Conditions Desktop Application

A Python-based desktop weather application built using Tkinter that provides real-time weather conditions and a 5-day weather forecast for any city using the OpenWeatherMap API.

---

## Features

- Real-time weather information
- 5-day weather forecast
- Dynamic weather icons
- Temperature display in Celsius
- “Feels like” temperature
- Minimum and maximum temperatures
- Clean graphical user interface using Tkinter

---

## Technologies Used

- Python
- Tkinter
- OpenWeatherMap API
- Pillow (PIL)
- Requests Library
